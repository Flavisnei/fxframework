# FX Artisan

FX Core e Symfony Console. Não instala HTTP, banco, Smarty ou FX Windows.

[Ajuda HTML offline](docs/index.html): instalação, exemplo, requisitos e limitações.

Pacote local em desenvolvimento. Veja o manifesto Composer e configure o repositório
path no projeto consumidor para instalar este componente e suas dependências FX.

Comandos de instalação: module:list, module:install e preset:install. Consulte a ajuda
HTML para os presets minimal/api/wordpress, modo --dry-run e configuração local @dev.
Instalar pacotes ainda não ativa módulos ou configura um painel.
