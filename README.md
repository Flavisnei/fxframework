# FX Modules

Gerenciador opcional de módulos, com dependência somente do Core.

[Ajuda HTML offline](docs/index.html): contrato, registro explícito, ativação,
desativação, bootstrap, atualização e recuperação de falhas.

Instale fx-console para os comandos module:status/doctor/enable/disable/refresh.
Estado por aplicação; sem migrations, rotas ou concessão de permissões automáticas.
