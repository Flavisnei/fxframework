# Referência local — etapa 8A, 08/09/2026

Rodada sintética com 20 amostras por cenário e duas rodadas descartadas, sem a
suíte de testes rodando junto. Código de aplicação da revisão `61fdec0`;
ferramentas de medição acrescentadas nesta entrega. Nenhuma otimização de runtime
foi feita nesta etapa. Veja [JSON integral](2026-09-08.json) e
[metodologia/comando](../../benchmarks/README.md).

Ambiente: Windows, PHP 8.1.12 CLI, 64 bits, OPcache CLI desativado, sem Xdebug.
SQLite via PDO: 3.36.0. As versões exatas e os hashes dos locks/scripts constam
no JSON. O ambiente existente serve como referência local; não é uma recomendação
de versões de produção nem uma matriz de compatibilidade atualizada.

¹ Pacotes físicos listados por Composer, incluindo pacotes FX, sem contar o

completa contém dependências de desenvolvimento, inclusive PHPUnit; os 16,84 MiB
não representam uma instalação de produção com `--no-dev`.

Os dois cenários Core executam o mesmo trabalho, com illuminate/container
10.49.0 em ambos. As diferenças de autoload e espaço descrevem os vendors medidos.
O p95 com apenas 20 amostras é sensível a ruído; não atribuir significado a pequenas
diferenças nem divulgar percentuais de ganho sem experimentos adicionais.

HTTP mede criação/boot da aplicação, registro de rota e resposta JSON. Contatos
mede somente despacho autenticado e paginação, com aplicação, usuário e 1.000
registros sintéticos preparados antes do cronômetro em SQLite na memória. Portanto,
esses tempos não são comparáveis entre si como custo completo de uma requisição.
Não houve rede, servidor HTTP, navegador ou concorrência neste experimento.

Pico é alocação PHP de todo o processo, incluindo preparação; não RSS. Corpo
exclui cabeçalhos, cookies, compressão e assets. Não some medianas de autoload e
operação como se fossem uma mediana de latência total. Inventário aquece arquivos,
e processos novos não equivalem a disco frio.

Conclusão permitida: há agora uma referência verificável de custo local e tamanho
instalado para orientar mudanças futuras. Não há comparação com Laravel, prova
de escalabilidade, medição de throughput, contagem instrumentada de SQL ou
certificação de workers persistentes. PHP/dependências modernas, CI, revisão
visual, outros bancos e distribuição continuam pendentes.
