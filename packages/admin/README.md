# FX Admin

Painel opcional FX Windows com contas, perfis, permissões e recuperação por callback.
Backend inicial: PDO SQLite; sem Eloquent ou Smarty.

[Ajuda HTML](docs/index.html): instalação, bootstrap, uso, operação e limites.

Instale fx-console para admin:init. O preset admin adiciona os pacotes; a configuração
e a primeira conta são explícitas. Releases públicas ainda não disponíveis.
