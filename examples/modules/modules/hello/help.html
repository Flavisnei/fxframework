Módulo Hello

Exemplo 1.0.0. Registra hello.message no container. Não acessa banco, HTTP ou sessão. hello.read é somente metadado; nenhuma permissão é concedida.

Usar

Em examples/modules, execute composer install, php vendor/bin/fxartisan module:enable hello e php index.php. Resultado: Modulo hello carregado.

Desativar

Execute php vendor/bin/fxartisan module:disable hello e php index.php. Resultado: Modulo hello inativo. Para consultar: module:status e module:doctor.

Problemas

Classe ausente: execute composer dump-autoload. Revise config/modules.json e a versão em fx-module.json. Mudou a versão: revise a alteração, execute module:refresh e module:doctor.

Teste isolado sem alterar o estado deste exemplo: php verify.php.
